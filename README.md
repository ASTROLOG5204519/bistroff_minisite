# Сайт фотографа Виталия Быстрова

Минималистичный сайт-визитка для фотосессий в Тбилиси.

## 🚀 Как опубликовать сайт бесплатно (за 2 минуты):

1. Создай новый репозиторий на GitHub (назови его, например, `vitaliy-site`).
2. Нажми ссылку **"uploading an existing file"** (загрузить существующий файл).
3. Перетащи сюда 3 файла: `index.html`, `style.css` и этот `README.md`.
4. Нажми зеленую кнопку **"Commit changes"** внизу.
5. Перейди в **Settings** (Настройки репозитория) → раздел **Pages** (слева в меню).
6. В пункте **Branch** выбери `main` (или `master`) и папку `/ (root)`. Нажми **Save**.
7. Подожди 1-2 минуты. Сверху появится ссылка вида: `https://твой-ник.github.io/vitaliy-site/`

Готово! Твой сайт работает и доступен всему миру.
